# Prakriti Ayurveda Website

A responsive static website for Prakriti Ayurveda, an Ayurveda clinic in Bur Dubai, Dubai.

## Files

- `index.html` — complete website structure and SEO metadata
- `style.css` — responsive design
- `script.js` — mobile navigation and appointment form
- `.gitignore` — Git ignore rules

## Deploy with GitHub Pages

1. Create a new repository on GitHub.
2. Upload these files to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

The site will be available through your GitHub Pages URL.

## Important

The appointment form currently opens the visitor's email client. For production lead capture, connect it to your preferred form backend or CRM.

Replace the placeholder visual/card design with licensed clinic photography if desired.
